# SF-Final-Project-PJ-4

# Real Estate Price Prediction

## Project Description

This project was completed as the final Machine Learning project.

The goal of the project is to build a machine learning model for predicting real estate prices based on property characteristics.

---

## Project Tasks

- Data loading
- Data cleaning
- Exploratory Data Analysis (EDA)
- Statistical analysis
- Feature Engineering
- Machine Learning
- Model comparison
- Model selection

---

## Dataset

The dataset contains more than 374,000 real estate listings in the United States.

Features include:

- property type
- state
- living area
- bedrooms
- bathrooms
- stories
- lot size
- year built
- remodeling information

Target variable:

- property price

---

## Models

- DummyRegressor
- LinearRegression
- RandomForestRegressor

---

## Best model

RandomForestRegressor

Results:

- MAE = 286,978
- RMSE = 1,516,952
- R² = 0.354

The Random Forest model improved MAE by approximately 39% compared with the baseline model.
